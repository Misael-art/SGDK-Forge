# Definition of Done

Para esta porta técnica: build pelo wrapper central, `out/rom.bin`, validação de recursos sem erros bloqueantes, memória/changelog sincronizados e smoke observado no BlastEm quando o host permitir.

Isso não equivale a jogo final, `ready_for_aaa`, qualidade visual aprovada, áudio aprovado ou 60 fps sustentados. Cada claim adicional exige o artefato e a evidência próprios.
