# Celestial Chase Revive

Projeto SGDK 2.11 para Mega Drive em fase de especificacao.

Status atual: `documentado`. Ainda nao existe ROM do Revive, build, captura BlastEm ou validacao de budget runtime. O benchmark `Celestial Chase visual benchmark [VER.001] [SGDK 211] [GEN] [LAB] [TECHDEMO]` foi analisado como referencia tecnica de escala, riscos e evidencias, nao como fonte de arte final nem como prova de entrega.

Nome canonico criado:

`Celestial Chase Revive [VER.001] [SGDK 211] [GEN] [GAME] [ACTION_RACING]`

O caminho sugerido inicialmente, sem `[TIPO] [GENERO]`, foi recusado pelo validador de nomenclatura do workspace. Este diretorio segue o padrao exigido:

`NOME [VER.XXX] [SGDK YYY] [PLATAFORMA] [TIPO] [GENERO]`

## Objetivo

Criar a base completa de producao para um jogo autoral de corrida/acao AAA-target no Mega Drive:

- abertura cinematica de alta qualidade;
- evento catalizador que acorda o Mestre Perseguidor;
- inicio jogavel da corrida;
- progressao por upgrades e power-ups;
- desfecho contra o Mestre Perseguidor.

## Gate de Verdade

Nada aqui deve ser chamado de pronto. O proximo passo de producao e transformar as specs em primeiro slice runtime, buildar ROM, validar recursos e observar no BlastEm.
