# Entrada Bruta Canonica

Coloque aqui os assets fonte do projeto.

Exemplos:
- `res/data/sprites/hero_sheet.png`
- `res/data/bgs/stage_forest.png`
- `res/data/ui/hud_panel.png`
- `res/data/branding/engine_logo.png`
- `res/data/branding/author_signature.png`
- `res/data/branding/project_logo.png`
- `res/data/branding/brand_hit.wav`

O `sgdk_wrapper` converte e espelha essa estrutura para `res/`.
