# Stage 2 — pântano no cais

`generated_stage2_v01.png` é a fonte original preservada. Ela foi produzida
com o prompt em `stage2_prompt.txt` e não é tratada como arte final até revisão
visual no emulador.

`convert_stage2.py` gera `res/gfx/bgb2.png` em 512×256, com entradas úteis
na grade de cor do Mega Drive e no máximo 768 tiles residentes. O relatório ao
lado registra hashes, paleta, contagem de tiles e o teto de qualidade.
