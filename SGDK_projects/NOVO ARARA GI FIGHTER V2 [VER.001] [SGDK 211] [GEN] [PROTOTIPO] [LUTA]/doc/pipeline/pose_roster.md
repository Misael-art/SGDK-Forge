# pose_roster

## Caio Arara Pose Roster

idle:
- frame 0 base stance
- frame 1 chest breath up
- frame 2 grip hands shift
- frame 3 knee settle
- frame 4 shoulder relax
- frame 5 return to base

walk_forward:
- lead foot slides
- rear foot recovers
- hands rise to grip
- hips stay low
- shoulders sway forward
- settle into base

walk_back:
- rear foot steps
- lead foot draws back
- torso guards
- hands check distance
- knees stay bent
- return to stance

dash:
- load
- penetration step
- forward drive
- brake into base

crouch:
- standing guard compressed
- low hip guard

jump:
- crouch load
- takeoff
- compact ascent
- peak
- descent
- landing base

guard:
- guard raise
- impact brace
- guard settle

jab:
- startup hand open
- active post
- active extension
- recovery

medium:
- load
- hip rotate
- active palm_or_low_kick
- follow-through
- recover

grip:
- reach
- sleeve/lapel target
- grip close
- pull check
- recover

hip_throw:
- enter
- establish grip
- step across
- hip turn
- load opponent line
- throw rotation
- release
- recover base

hurt:
- contact
- torso recoil
- arm flare
- regain base

knockdown:
- hit bend
- fall start
- side drop
- back/contact mat
- settle
- down hold

getup:
- guard on ground
- post hand
- technical stand-up leg retract
- hip rise
- base rebuild
- neutral
