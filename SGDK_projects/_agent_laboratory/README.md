# Agent Laboratory Workspace

Status: `controlled_laboratory_area`

Use esta pasta para experimentos isolados do agente.

Regras:

- cada experimento vive em uma subpasta propria;
- use nomes com `[LAB]` ou `[TECHDEMO]`;
- todo material externo usado deve ser copiado para `rascunho/` do subprojeto;
- cada experimento deve registrar `doc/lab_report.md`;
- resultado de laboratorio nao e entrega;
- laboratorio nao promove tecnica para `MESTRE_*`.

Workflow:

- `tools/sgdk_wrapper/.agent/workflows/laboratory-mode.md`
