# Agent Training Workspace

Status: `controlled_training_area`

Use esta pasta para projetos de treino do agente.

Regras:

- cada treino vive em uma subpasta propria;
- use nomes com `[LAB]` ou `[ESTUDO]`;
- todo material externo usado deve ser copiado para `rascunho/` do subprojeto;
- treino pode gerar licoes locais em `doc/agent_learning/`;
- treino nunca aplica patch canonico automaticamente;
- treino nunca declara `ready_for_aaa=true`.

Workflow:

- `tools/sgdk_wrapper/.agent/workflows/agent-training-mode.md`
