# SSEngine_Engines — Engines Web/Browser para Emulação e Jogos Retro

## Visão geral

Esta pasta agrupa engines open-source de qualidade para emular e jogar jogos retro diretamente no navegador.
São engines completas, já em produção, com código aberto, documentação e comunidade ativa. Primeiro
destino para quem quer estudar como uma engine web funciona "do zero" até o resultado final em YAML.
