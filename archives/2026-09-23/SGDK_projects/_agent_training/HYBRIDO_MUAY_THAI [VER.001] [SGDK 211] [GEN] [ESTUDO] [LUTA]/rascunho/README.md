# Rascunho do Projeto

Area local para material ainda nao promovido.

- `entrada_bruta/`: copias locais de fontes externas, com origem, autorizacao e hash registrados em `doc/project_hygiene_manifest.json`.
- `processado/`: resultados intermediarios ainda nao promovidos para `data/`, `res/`, `src/` ou `doc/`.
- `temporario/`: arquivos descartaveis da iteracao ativa.

Nenhum arquivo desta pasta serve como evidencia de entrega ate ser promovido, documentado e validado. Rascunhos nao devem ser criados na raiz do projeto nem na raiz do workspace.
