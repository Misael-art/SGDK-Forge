# Gate de release — v0.1.0

Data: 2026-08-06  
Escopo: distribuição pública de fonte do framework SGDK Forge.

## Decisão

**Aprovada como `source_framework_release`.** A tag pode distribuir o repositório,
o template, o wrapper e os contratos de fixture. Ela não aprova uma ROM, jogo,
vertical slice, desempenho, áudio ou claim `ready_for_aaa`.

## Matriz de claims

| Claim | Owner / artefato | Estado |
|---|---|---|
| Download reproduzível de fonte | GitHub tag e archive automático | aprovado |
| Onboarding do usuário | `README.md` e `sdk/README.md` | aprovado |
| Contratos técnicos neutros | `canonical_fixture_gate.py` | aprovado por testes |
| Vínculo de aprendizado a uma ROM | `learning_evidence_binding.py` | aprovado por testes |
| ROM distribuível | build + hash + BlastEm | não provado |
| Jogo completo / AAA | GDD, runtime, budget e QA | fora de escopo |

## Blockers conhecidos

- O SDK binário não é versionado; cada consumidor deve instalar/configurar SGDK
  2.11 conforme `sdk/README.md`.
- A rota Linux de build SGDK não possui certificação de release nesta `main`.
- `FORGE_REFERENCE` tem `build_policy=disabled`; é referência de contratos, não
  ROM validada.

## Próxima promoção permitida

Uma release que inclua ROM precisa anexar build identificada por SHA-256,
`validation_report`, evidência nova de BlastEm e os eixos de gameplay,
performance, áudio e budget aplicáveis ao projeto.
